# Passerelle

Envoyer des fichiers entre ordinateurs Windows et macOS, à côté ou à distance, et depuis un téléphone.

## Télécharger

**[➜ Dernière version](https://github.com/Dapheureux/passerelle-telechargements/releases/latest)**

| Système | Fichier |
|---|---|
| Windows 10 / 11 (64 bits) | `Passerelle_<version>_x64-setup.exe` |
| macOS (Apple Silicon et Intel) | `Passerelle_<version>_universal.dmg` |

Une fois installée, Passerelle se met à jour toute seule : un bandeau propose la nouvelle version, un clic suffit.

Les fichiers ne sont pas encore signés par Microsoft ni Apple :

- **Windows** : si « Windows a protégé votre ordinateur » s'affiche, cliquez sur *Informations complémentaires*, puis
  *Exécuter quand même*.
- **macOS** : la première fois, faites un *clic droit › Ouvrir*.

Les mises à jour, elles, sont signées par Passerelle : l'application refuse toute mise à jour qui ne vient pas de nous.
